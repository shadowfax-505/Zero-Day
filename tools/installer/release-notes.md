Zero Day is a turn-based strategy game where a Red intruder AI and a Blue defender AI play each other on a network neither can fully see. Watch the two AIs play or take one side yourself.

## Download

No Python or other setup needed. Pick the file for your computer below.

| System | Download | How to start |
| --- | --- | --- |
| Windows 10 and 11 | **ZeroDay-Windows-Setup.exe** | Run it. It adds Zero Day to the Start menu (no admin rights needed). |
| Windows, no install | ZeroDay-Windows-Portable.zip | Unzip it and run `Zero Day.exe` |
| Mac with Apple chip (M1 to M4) | **ZeroDay-macOS-AppleSilicon.dmg** | Open it and drag Zero Day to Applications |
| Mac with Intel chip | **ZeroDay-macOS-Intel.dmg** | Open it and drag Zero Day to Applications |
| Linux (x86_64) | **ZeroDay-Linux-x86_64.AppImage** | Make it executable (`chmod +x`) and run it |
| Linux, plain folder | ZeroDay-Linux-x86_64.tar.gz | Extract it and run `Zero Day/Zero Day` |
| Phone, tablet or anything else | [Play in the browser](https://shadowfax-505.github.io/Zero-Day/) | Nothing to install |

Not sure which Mac you have? Open the Apple menu and choose **About This Mac**. "Chip: Apple M..." means Apple chip and "Processor: Intel" means Intel.

### The first time you open it

The apps are not signed with a paid developer certificate, so the system asks once before it opens them.

- **Windows:** if SmartScreen says "Windows protected your PC", click **More info** then **Run anyway**.
- **macOS:** if it says the app "cannot be opened", open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Zero Day. On macOS 14 or older you can also right-click the app, choose **Open** then **Open** again.
- **Linux:** if the AppImage does not start, install FUSE (`sudo apt install libfuse2` or `libfuse2t64` on Ubuntu 24.04 and newer) or run it with `--appimage-extract-and-run`.

## Modes

- AI vs AI with Full, Red and Blue views
- Human vs AI as either side
- Online play on the same network, by IP or with a room code
